# 社群消息与账号绑定管理

## 入口与机器人配置

管理员进入原有「成员绑定」页面 `/admin/community/members`，在「社群成员」和「群消息」标签页之间切换。群消息、头像详情和按工单解绑均在该页面内完成，不需要增加或替换侧栏菜单。

1. 在「机器人设置」`/admin/communications` 保存 Telegram 机器人令牌、Webhook 验证密钥和回调地址。
2. 回调地址使用本站公网 HTTPS 域名，例如 `https://example.com/api/v1/support/telegram/webhook`。域名、证书和反向代理需要允许 Telegram 访问这一地址。
3. 保存配置时，服务器会调用 Telegram 注册回调，订阅 `message`、`edited_message`、`chat_join_request` 和 `chat_member`。升级后会为已有有效配置自动补充新订阅；注册失败会重试，必要时可重新保存机器人设置。
4. 在「社群与 VIP」`/admin/community/settings` 填写私密群的负数 Chat ID、群组名称及机器人用户名并启用。机器人需为该群管理员，并具有邀请用户、封禁用户权限；从网页发群消息还需要机器人具有发言权限。

单个 Telegram 机器人只能配置一个 Webhook。不要让其他机器人平台覆盖本站的回调配置。工单与社群复用本站的同一个回调入口。

## 查看群消息和成员

「群消息」标签页自动刷新新消息，也可以手动刷新或加载更早的已存记录。点击普通成员头像或姓名，可以查看 Telegram 用户 ID、用户名、显示名称，以及匹配的网站账号、绑定状态和禁入状态。尚未绑定的网站身份显示为空；匿名管理员或以频道身份发送的消息不能识别为某个普通 Telegram 用户。

群消息记录存在以下边界：

- 只记录接入后机器人实际可见、并由 Telegram 推送给本站的消息。机器人权限和 Telegram 可见性规则仍然适用，不能保证收到群内所有消息。
- 不能补拉接入前的完整群历史；「加载更早消息」只读取本站已经保存的记录。
- 编辑后的消息作为独立记录保存，保留此前已收到的原文。
- 当前不会自动同步 Telegram 群内的消息删除，群内删除不代表网站记录也已删除。
- 图片、语音、视频和文件按需加载，当前最多下载 20 MB。超过限制、无法获取或属于旧机器人的附件，请在 Telegram 中查看。

## 从网页发送群消息

管理员在「群消息」底部输入纯文本，点击「发送到群」。消息以已配置的机器人身份发送，并记录网站管理员身份。当前网页不支持上传附件。

单条消息最多 4096 个 UTF-16 代码单元；常见中文通常计为一个，部分表情计为两个。系统按群限制每分钟最多 20 次新发送请求。

若页面提示发送结果尚未确认，请先检查 Telegram 群。相同发送请求不会自动重复广播，以免网络超时后重复发出已经送达的内容。明确失败后，可根据错误信息修正权限或稍后重新发送；结果未知时，不要通过改字或刷新页面来强行重复发送。

## 入群与绑定状态

用户在 `/community` 领取个人邀请。首次有效申请会锁定对应 Telegram 账号，系统在确认资格后处理入群申请；成功入群后邀请失效。已经在群内但网站状态未恢复的用户，可以使用「已在群内，核对身份」，在机器人私聊中核对并回网站确认本人身份。

绑定确认后，用户不能自行解除或换绑 Telegram 账号。状态含义如下：

| 状态 | 含义与后续操作 |
| --- | --- |
| `pending` | 已领取邀请或正在核对入群，尚未确认已在群内。 |
| `joined` | 已确认加入群组。 |
| `left` | 用户自行退群，原绑定保留；符合资格时可使用原 Telegram 账号再次领取邀请加入。 |
| `banned` | 管理员将其移出群组，显示持久红色禁入提示，禁止再次领取邀请或加入。 |

Telegram 中解封以及管理员解除网站绑定，都不会清除站内禁入记录。被禁入的网站账号与 Telegram 身份仍受限制；即使用户不再符合 VIP 资格，页面也保留禁入提示。

## 根据本人提交的工单解除绑定

1. 用户在 `/tickets` 提交解绑工单，说明需要核查的账号绑定。
2. 管理员核实工单确由目标网站用户本人提交，且提交时间不早于这次绑定；同一工单不能重复用于解绑。
3. 在 `/admin/community/members` 找到该用户，打开头像详情，填写工单 ID，并勾选已经核实申请人与绑定信息的确认项。
4. 点击「解除绑定」。服务器会再次校验管理员身份、工单归属和可用性，撤销当前邀请及验证信息，解除绑定并保存审计记录。

解除绑定操作只解除网站与 Telegram 账号的关联，不清除禁入记录，也不等同于将成员从 Telegram 群中移除。未禁入的用户可以重新确认新账号；已禁入用户仍会看到禁止重新加入的提示。

## 回调与状态排查

- 私聊机器人没有回复时，检查「机器人设置」是否已经保存有效回调，以及公网是否能访问该回调。普通私聊与 `/start` 会返回社群使用指引；身份核对必须使用网站生成的个人链接。
- 入群申请未被处理时，检查机器人邀请权限、群 ID 和回调订阅。页面刷新会对已经授权但仍待确认的成员核对 Telegram 实际状态；旧邀请未形成绑定时，按页面提供的身份核对流程恢复。
- 页面没有群消息时，先检查机器人能否在 Telegram 中看到新的群消息，再检查回调投递；接入前历史不会因刷新自动出现。
- 保存配置或发送失败时，按页面具体报错检查对应字段或权限，不要向工单或聊天中发送机器人令牌、Webhook 密钥。
