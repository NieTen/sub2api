# 工单回复邮件提醒

## 设置入口

1. 管理员打开「系统设置 → 邮件设置」，填写并保存 SMTP 服务器、端口、发件人和认证信息。
2. 开启「启用工单回复邮件通知」。升级后该开关默认开启，也可以单独关闭。
3. 在同一页面的「邮件模板」中选择「工单回复通知」，编辑主题和正文，预览后保存。中文与英文模板分别保存，也可恢复默认模板。

邮件中的工单跳转链接使用系统配置的前端网站地址（`frontend_url`）。请填写用户可访问的完整网站地址；未配置地址时，用户仍可自行登录网站查看和回复工单。

管理员从网页或 Telegram 回复工单后，系统会向该工单用户的有效邮箱发送提醒。用户自己回复工单不会收到自己的回复提醒。Telegram 回复需要先在机器人管理页配置机器人及授权管理员。

用户回复提醒独立于机器人管理页的通知总开关。关闭机器人通知不会关闭用户邮件提醒；要关闭用户邮件，请使用邮件设置中的专用开关。

## 模板变量

| 变量 | 内容 |
| --- | --- |
| `{{site_name}}` | 站点名称 |
| `{{recipient_name}}` | 用户名称 |
| `{{recipient_email}}` | 用户邮箱 |
| `{{ticket_id}}` | 工单编号 |
| `{{ticket_subject}}` | 工单标题 |
| `{{reply_content}}` | 管理员回复正文，自动转义为安全文本 |
| `{{reply_time}}` | 回复时间 |
| `{{ticket_url}}` | 网页工单入口，使用系统配置的网站地址 |
| `{{reply_images}}` | 回复中的图片，以内嵌图片形式展示 |

保留默认模板的正文样式可显示回复中的换行。图片随邮件发送，读取图片不需要公开工单附件地址。若自定义模板要展示图片，请保留 `{{reply_images}}`。

## 投递与排查

- 先用邮件设置中的测试功能确认 SMTP 配置可用，然后向一个测试账号的工单回复。
- 邮件通过后台队列异步发送；SMTP 故障时按现有重试机制重试，不影响工单回复保存。
- 每个成功收件人分别记录投递回执，失败收件人重试时不会再次发送给已有回执的收件人。
- 无有效邮箱的账号不能接收邮件提醒，仍可在网页中查看工单回复。
- 这些设置需要更新到包含本功能的版本后才会出现在网站后台。
