# 桌面端控件审查与前后对照

## 记录状态与范围

日期：2026 年 10 月 3 日至 4 日。

**六个后台模块已完成 1440×900 浏览器前后截图与下文列明的操作验收；1024×768 暗色、1920×1080 下六页均未出现页面横向溢出。用户社群的指定状态与共用下拉的右下边缘定位也已实测。通过结论仅限已列场景，未覆盖的错误、媒体和状态组合由源码与单测补充，不标记为全部实测通过。**

本轮使用 `ui-ux-pro-max` 技能，针对用户要求的桌面按钮、下拉、状态与布局做调整。范围为通知配置、VIP 社群设置、邮件群发、工单、成员绑定、质量检测六个后台模块，以及关联的用户社群页面、局部组件和共用 `Select`。保持原青色主题、路由、API、业务规则与项目架构，不引入依赖。

本轮“修改前”是上一轮窄屏修正之后、桌面调整之前的工作区快照，不能用 Git HEAD 或旧手机截图替代。此前的窄屏记录保留在 [UI 缺陷审查与前后对照](UI缺陷审查与前后对照.md)。审查阶段不修改版本、不发布；后续经用户授权纳入 v0.2.13.3。

证据分为三类：源码检查确认实现与状态条件；定向自动化验证事件和请求参数；浏览器检查确认实际展开、焦点、布局与尺寸。三者分别记录，不相互替代。浏览器使用本地模拟 API，不向真实邮箱、Telegram 或支付平台发送请求，不打开测试外部邀请链接。

## 共用 Select 的修改与检查

共用文件：`components/common/Select.vue`。已结合源码、定向测试和真实浏览器核对下列指定场景；不推定所有使用页面及定位边界均已覆盖。

| 修改前 | 当前调整 | 验证证据与边界 |
| --- | --- | --- |
| 清除元素嵌套在触发按钮中，不能作为独立原生按钮参与 Tab 顺序 | 清除改为触发按钮旁的原生按钮，补名称和焦点；清除后关闭菜单并回到触发器 | 真实浏览器：Tab 可到清除，Enter 清除成功；定向测试补充焦点恢复 |
| 触发器及列表关系不完整 | 补 `aria-haspopup="listbox"`、列表标识、`aria-controls` 和活动项；搜索框使用 combobox 语义 | 源码核对语义；真实浏览器 Escape 只关闭菜单，不误关弹窗 |
| 右边缘及上下可用空间不足时菜单可能挤出可用区域 | 限制左右边界和菜单最大高度；比较上下空间，内容内部滚动 | 普通位置及右下边缘已实测；1024／1440／1920px 下30项菜单未超出视口，坐标见下表 |
| 分组条目可能参与键盘选项移动 | 分组标题与禁用项均不可选择 | 源码与定向测试补充，不冒充所有分组数据已浏览器实测 |
| 从 Teleport 菜单按 Tab 会脱离原表单顺序 | 先回到触发器再关闭菜单，由浏览器继续默认 Tab 顺序 | 真实浏览器：Tab 到清除、Shift+Tab 到前一个输入；弹窗末尾 Tab 回关闭按钮；关闭弹窗后恢复打开按钮 |
| 打开后进入禁用状态时菜单仍可留下 | 禁用时关闭菜单 | 源码与定向测试补充；不扩大为所有父表单保存组合均实测 |
| 已有选项的远程加载缺少提示 | 菜单内补加载状态；选项变化后重新计算方向与空间；保留远程查询和清除事件约定 | 已核对 `filteredOptions` 变化后重新定位；浏览器已测窗口缩小时重新定位，远程结果变化与边缘的全部组合未逐一实测 |
| 减少动态效果偏好未针对菜单过渡处理 | 该偏好下取消菜单进出过渡 | 源码核对；未单列为浏览器实测项 |

只读审查未发现阻塞级兼容问题。BaseDialog 在文档冒泡阶段处理键盘事件；Select 的 Escape 已阻止默认行为，真实浏览器确认只关菜单。Tab 会先将焦点放回触发器，使弹窗按实际表单首尾处理约束；上述真实浏览器 Tab、Shift+Tab、清除和关闭恢复场景已通过。该结论来自实际浏览器操作与单测共同验证，不仅依赖 jsdom。

## 后续更新要求

每次 AI 新增或修改页面都继续使用技能检查，并更新中文前后对照。实际浏览器检查完成后再补截图、测量和结论；未发现缺陷的页面保留，不为增加“优化数量”改造业务或引入新组件体系。只有明确要求发布时才进入版本和发布流程。

**最终交付必须保留的业务限制：**成员绑定默认筛选目前仍为 `all`，不是用户此前要求的“仅显示已入群”；这在本轮起点已经如此，本轮只保持既有行为。邮件群发在“选择用户”模式下，即使配置余额或充值条件，审核与创建草稿仍要求至少选择一名用户；这也是现有业务规则，本次桌面 UI 没有修复该历史需求。成员详情当前只有身份、状态和按工单解绑，没有新增充值／并发记录查询或独立禁入管理接口。不得把视觉调整、模拟 API 或定向测试表述为上述业务诉求已经全部完成。
