    验证边界与未补齐的业务需求

    • 本地模拟接口：截图来自真实 Vue 页面与合成数据，保存、检测、发送等操作使用内存响应；未发送真实邮件、Telegram 消息或模型请求，不能据此认定生产环境联调完成。
    • 邮件群发仍是纯文本：本轮未新增富文本编辑、实时富文本预览或多风格模板。在“选择用户”模式下，即使设置余额或充值条件，仍须至少选择一名用户。
    • 成员绑定默认仍为全部状态：未改为默认仅显示已入群账户；详情入口打开的是既有身份与解绑信息，未增加充值、并发变动记录或独立禁入管理 API。
    • 本轮是桌面 UI 调整：已完成本地修改，尚未发布。截图不是每一种错误、媒体、权限或禁用组合的全覆盖证明；具体实测与待验收项保留在详细审查记录中。
