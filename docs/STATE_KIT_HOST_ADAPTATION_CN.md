# STATE Kit 宿主适配说明

本功能为已经安装的 STATE Kit 提供宿主接口和配置页通信支持。它不安装、更新或修改插件，不把插件的票据采集、代理链、刷新调度或模型请求算法写入宿主。

源补丁基于官方 Sub2API 0.2.7；本仓库按当前架构增量适配，不能直接覆盖旧补丁里的协议生成文件或装配代码。源项目的 `overlay/` 面向旧版宿主，本次不引入该目录，也不引入其中的票据处理算法。

参考项目按 LGPL-3.0 授权；本次保留其协议来源说明及原有许可，不变更插件包的版权和许可。

## 使用入口和开关

进入管理员后台的“插件管理”，在对应插件卡片中开启“宿主适配”。每个插件分别保存开关状态，默认关闭；开关变更沿用管理员敏感操作校验。

1. 确认 STATE Kit 已安装。该适配不会重复导入插件。
2. 开启该插件卡片的宿主适配。已运行插件会安全重载，使握手和新增接口状态同步生效。
3. 打开插件配置页，读取分组、账号和代理目录。读取目录本身不要求启动插件，也不会发送模型请求。
4. 需要执行手动测试时，先在插件管理中启用插件，再使用插件配置页中的测试或查找按钮。
5. 自动采集及各账号是否参与，由插件自己的总开关、账号开关和配置决定。

**宿主适配开关不是插件总开关。** 关闭适配只收回新增的适配接口和预览权限，不会替代插件的停用操作，也不会删除插件配置、账号或代理。要停止插件转发及后台工作，应使用插件管理中的停用操作，并根据需要调整插件本身的配置。

已选择“IP 管理中的代理”时，关闭适配会使该代理 ID 无法通过适配接口继续解析。插件应按自身逻辑报告不可用，宿主不会将其悄悄改为直连。需要继续使用不依赖目录的插件能力时，可先按插件提供的选项调整配置。

## 权限与数据边界

- 新增网页接口仅管理员可访问；提交手动动作和修改开关沿用敏感操作验证。
- 资源及代理接口同时检查宿主适配开关和插件被授予的能力范围，不能仅靠页面按钮控制权限。
- STATE Kit 声明的能力为 `openai.oauth.outbound_transport.v1`，对应平台 `openai`、账号类型 `oauth`。插件不能通过请求参数扩展账号范围。
- 页面资源目录只返回账号 ID、名称、分组 ID，分组 ID、名称，以及代理 ID、名称、协议、主机和端口。不会把完整账号对象、令牌或代理认证信息发给插件页面。
- 管理员选择目录包含授权范围内各状态的普通 OAuth 账号，便于提前配置；不包含影子账号。插件后端的自动枚举和身份解析继续采用原有可用账号范围，不因网页可见而恢复、启用账号或扩展权限。
- 可用代理目录排除禁用和过期代理。按 ID 解析时重新检查，代理被删除、禁用、过期或解析失败时不提供直连兜底。
- 代理认证地址只经宿主到插件进程的服务接口提供，不出现在页面资源目录中。插件收到的现有出站身份仍受原账号范围限制。
- `plugin.resources` 和被动状态查询不能触发采集或测试。手动动作只使用已经运行的插件，不创建临时插件进程执行操作。
- 动作请求限制为单个、大小受限的 JSON 对象；请求 ID 用于关联结果和支持插件去重。长时间测试的进度通过插件状态查看。

## 协议兼容和预览隔离

当前宿主的第二版账号协议已经提供名称、状态、可调度性等元数据。本次保留 `ListAccountsResponse.accounts` 和 `AccountInfo`，并保留旧版 `account_ids` 字段，新增资源接口只输出所需的安全字段。

参考版本的 STATE Kit 严格要求第一版宿主服务握手。因此，兼容握手仅用于宿主适配已开启、插件 ID 为 `io.github.wangyunjeff.sub2api-state-kit` 的安装。其他插件继续使用当前宿主协议版本，不进行全局降级。

插件页面继续使用不带同源权限的沙箱，页面通信校验当前框架、会话令牌和请求 ID。HTML 预览由插件自己的内层沙箱完成；宿主只允许所需的嵌套文档，不授予同源、外部联网、表单提交或顶层导航权限。关闭或切换配置页后，旧请求不能向新页面传递结果。

## 排查要点

- **仍只能手填账号 ID：** 检查对应插件的宿主适配开关及配置页是否已重新打开；目录请求失败时不要把空目录当作保存成功。
- **目录能显示，但手动操作不可用：** 检查插件是否已启用，以及插件状态是否报告宿主服务和动作接口可用。目录读取与插件运行相互独立。
- **代理名称存在但采集失败：** 检查代理当前启用状态、到期时间和认证信息；目录名称并不代表连接测试已经通过。
- **开启后仍提示等待宿主：** 检查已运行插件是否完成重载及握手。旧版本 STATE Kit 严格校验服务版本，仅增加资源接口不能解决握手问题。
- **票据或模型测试失败：** 查看插件提供的运行记录和错误；宿主适配只提供通信及授权能力，不保证代理、上游服务或插件算法的执行结果。

本次不会自动修改插件发布者信任配置、签名清单或版本兼容声明。插件自身升级仍按现有插件管理流程处理。
