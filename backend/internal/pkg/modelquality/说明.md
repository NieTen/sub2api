# 轻量能力基准

本目录是本项目独立实现的标准库 Go 能力题库，与 ModelTrace 的模型指纹归因分开评分。

每轮包含十种固定难度范围的题型，随机替换操作数或输入内容：整数算术、余数、递推数列、不相邻排列、逻辑必然性、文本指令执行、分数运算、条件循环、容斥计数、不放回抽样概率。全部标准答案由代码计算，一次模型请求返回 JSON 答卷，不依赖另一个模型充当裁判。

每道题占十分。无效 JSON、缺失题号、重复题号、未知题号或不可解析的答案类型属于检测错误，返回错误且不生成能力分数；完整答卷里的错误答案正常扣分。首次检测没有历史基线；不同题库版本、模型或采样配置不应直接比较。单轮低分只能解释为本题组表现下降，不能证明模型被替换或总体智力下降。

题库版本为 `modelquality-v1`。修改难度、题型或判分标准时应递增版本，以避免混用历史基线。
