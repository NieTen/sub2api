# ModelTrace 核心来源

本目录将 [ModelTrace](https://github.com/xqy2006/ModelTrace) 的核心数字指纹算法改写为标准库 Go 实现，直接集成到本项目，不调用外部 ModelTrace 服务，也不需要 Python、NumPy 或 Node.js 运行时。

- 上游提交：`df3a0f9d3e054c0dc02d6d586686db8daf8fa7c8`。
- 原作者版权：`Copyright (c) 2026 xqy2006`。原始 MIT 许可证全文保存在 `LICENSE.ModelTrace`；发布本项目时应一并保留。
- 算法来源：`fingerprint.py`、`static/fingerprint-core.js`；挑战来源：`fingerprint.py` 的 `generate_challenges`。
- 嵌入数据来源：`data/unified_bank.json`，包含 16 个 GPT / Claude 模型的完整统计指纹与校准参数。
- 数据统一为 UTF-8 / LF 后的 SHA-256：`1c2cb74d372f9f0f30d0dabbb7b7a838660d2f769a88d0c8489e4c662e088c21`。
- 上游致谢：`hanlinwenyuan/hlwy-ai-checker` 对随机数字生成偏差应用的研究。

## 保留的算法

保留最长数字段解析、Hellinger 特征、环境干扰方向投影、四段数字直方图及尾数特征、环境模板最大匹配、分数标准化、0.75 / 0.25 融合、按有效回答数选择温度的全局 softmax、家族概率聚合以及 Jensen–Shannon 相似度。运行时直接加载编译进二进制的完整指纹库，不重新训练。

## 解释限制

概率是候选库内、均匀先验下的闭集归因结果。库外模型也可能非常接近某个库内候选；系统提示词、采样参数和提供方环境均可能改变指纹。因此不得把本结果表述为实际模型身份的认证、智商测量或能力下降的确定证据。独立能力题的评分由本项目 `modelquality` 包负责，不属于 ModelTrace 算法。

## 离线一致性验证

`testdata/parity.json` 从相同上游提交的 `gpt_reference.jsonl` 和 `claude_reference.jsonl` 中，逐模型取最先出现的三份有效参考回答，使用上游 JavaScript 核心计算 1、2、3 份回答的结果，共 48 个案例。Go 测试比较完整候选列表、分数、概率、相似度、家族结果及诊断，浮点误差上限为 `1e-10`。

`testdata/generate-parity.mjs` 仅用于维护时重新生成夹具，读取本地上游参考源码目录，不执行模型请求。正常测试和应用运行均不需要 Node.js。这些保存的训练参考数据只证明移植数值一致，不证明真实未知请求的独立准确率。
